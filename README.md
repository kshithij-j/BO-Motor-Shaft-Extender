# BO Motor Shaft Extender

A 3D-printable shaft extender designed for **BO motors used in small RC cars**.

The adapter attaches to the BO motor's existing shaft and extends it outward, allowing the shaft to pass through materials such as **cardboard, foam board, acrylic, or thin sheet material** and provide a suitable mounting point for an RC-car wheel.

## Features

* Designed for BO motor shafts
* Extends the usable shaft length
* Suitable for DIY RC car chassis
* Can pass through cardboard or similar chassis materials
* 3D printable
* Simple press-fit / screw-secured design depending on the included model
* Lightweight and easy to manufacture

## Use Case

This part is useful when the original BO motor shaft is too short to reach through the RC-car chassis and properly mount a wheel.

The extender allows the motor to remain mounted inside the chassis while providing a longer axle outside the chassis for the wheel.



## Important

The exact fit depends on the BO motor shaft dimensions and the printer's dimensional accuracy. Test-print the shaft interface before printing multiple copies.
For minor fix using a sanding tool.
